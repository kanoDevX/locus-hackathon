# UstazAI — персональный маршрут поступления

**LOCUS Startup Hackathon 2026 · Кейс 02 «Персональный маршрут поступления» · код `LOCUSCASE2`**

UstazAI превращает профиль и цель абитуриента из Казахстана в понятный маршрут: **куда поступать,
почему именно этот вариант и что сделать следующим шагом**. Это не AI-чат и не каталог вузов:
шансы считает детерминированная модель, а Gemini только объясняет уже посчитанные цифры внутри
структурированного продукта с защитными правилами на уровне кода.

## Задача и решение

**Аудитория.** Школьники 9–11 классов и выпускники колледжей Казахстана, поступающие на бакалавриат
дома (ЕНТ, гранты) и за рубежом. Учтены разные пути: стандартный ЕНТ, творческий экзамен, смена
специальности, продолжение специальности после колледжа (грант или платно), «не сдаю ЕНТ».

**Путь пользователя (7 этапов кейса).**
1. **Вход**: ценность сервиса и ожидаемый результат (ru/kk/en).
2. **Профиль**: класс, интересы, GPA, экзамены, страны, бюджет и сроки, предпочтение «только грант».
3. **Диагностика**: сильные стороны, ограничения, цель, уверенность.
4. **Рекомендации**: минимум 3 программы с объяснением «почему подходит» по 4 факторам и оценкой
   шансов с неопределённостью.
5. **Сравнение**: таблица параметров и карта вуза с окружением.
6. **Roadmap**: экзамены, документы, дедлайны, считаемые назад от реальных сроков программы.
   К каждой задаче есть пошаговый гайд «Учить» со ссылками на видео.
7. **Следующее действие**: один выделенный шаг и отметка прогресса.

**Изменение ответа меняет результат.** Повторное сохранение профиля показывает, что изменилось
и какие этапы затронуты; пересчёт рекомендаций показывает добавленные, убранные и сдвинутые
программы. Есть симулятор «что если».

## Чем это отличается от чата и каталога

- **Модель считает, LLM объясняет.** `HybridScoringEngine` и `GrantEligibilityEngine`: чистый
  C# без фреймворков, покрыт тестами. Gemini не изобретает цифры.
- **Честность данных.** Каждое число имеет происхождение: «Демо» или «Проверено» с источниками.
  Кнопка «Проверить через интернет» запускает поиск Gemini + Google Search; без цитируемых
  источников ничего не записывается, значения проверяются на границы и согласованность.
- **Реальная логика Казахстана.** Три уровня порогов ЕНТ, гранты, альтернативные треки.
- **Деньги без иллюзий.** Уровни доступности (доступно / впритык / за рамками бюджета). Для режима
  «только грант» бюджет не спрашивается, считается покрытие стипендией.
- **Guardrails.** Ответ AI очищается от гарантий поступления и абсолютных обещаний.
- **Деградация без падения.** Если AI недоступен, работают детерминированные тексты на ru/kk/en,
  а в интерфейсе виден бейдж «резервный режим».
- **Язык интерфейса = язык AI-текста.** Заголовок `X-Locale` управляет языком ответов.
- **Журнал решений AI** и страница метрик (вызовы, задержка, доля резервных ответов).

Дополнительно: оценка шансов на грант, стипендии, календарь дедлайнов, избранное, эссе-ревью,
чат по данным пользователя, peer pathways, карта вуза (Leaflet + OpenStreetMap/CARTO, без ключей).

## Технологии

- **Frontend**: Next.js 16 (App Router), React 19, TypeScript, Tailwind, TanStack Query, Zustand,
  react-hook-form + zod, next-intl, Leaflet.
- **Backend**: .NET 10, minimal API, MediatR (CQRS + pipeline: validation, logging, guardrails),
  FluentValidation, EF Core 10, SQL Server, JWT + BCrypt, Serilog, Polly (таймауты, retry,
  circuit breaker).
- **База**: SQL Server (локально Express/Docker, в облаке Azure SQL).
- **AI**: Google **Gemini** по REST со структурированным выводом (`responseSchema`), Google Search
  grounding для проверки данных, цепочка резервных моделей с переходом при исчерпании квоты (429)
  и перегрузке (503).
- **Тесты**: xUnit, FluentAssertions, NSubstitute, WebApplicationFactory: **80 тестов**.

## Архитектура

```
Next.js (ru/kk/en) ──HTTP/JSON, X-Locale──▶ ASP.NET Core minimal API
                                                │  MediatR pipeline: Validation → Logging → Guardrail
                                                ▼
                       Application (команды/запросы) ──▶ Domain (скоринг, допуск, roadmap, what-if)
                                                │
                                   Infrastructure: EF Core / SQL Server, Gemini client (fallback chain), JWT
```

## Запуск локально

Backend (нужен SQL Server Express или Docker):
```bash
cd UstazAI/UstazAI
# один раз: задать секреты (или положить их в appsettings.Development.json, он в .gitignore)
dotnet user-secrets set "Jwt:SigningKey" "<не менее 32 случайных символов>"
dotnet user-secrets set "Gemini:ApiKey" "<ключ из aistudio.google.com>"
dotnet run --urls http://localhost:5087
```
Frontend:
```bash
cd UztazAIDesktop
cp .env.local.example .env.local   # NEXT_PUBLIC_API_BASE_URL=http://localhost:5087
npm install && npm run dev
```
Docker: `cd UstazAI && cp .env.example .env && docker compose up`.

Секреты не хранятся в репозитории: `appsettings.json` содержит только пустые значения, реальные
задаются переменными окружения (`Jwt__SigningKey`, `Gemini__ApiKey`, `ConnectionStrings__Default`).
Для нескольких ключей Gemini: `Gemini__ExtraApiKeys__0`.

## Тестовый сценарий для жюри

1. Откройте сайт, войдите как `judge@ustazai.demo` / `JudgePass123!` или зарегистрируйтесь.
2. Пройдите анкету и шаг экзаменов (для ЕНТ введите баллы; можно выбрать «не сдаю ЕНТ»).
3. Посмотрите **Диагностику** и **Рекомендации**, откройте «почему подходит».
4. Выберите 2+ программ, откройте **Сравнение**, вкладку «Карта».
5. Сгенерируйте **Roadmap**, откройте «Учить» у любой задачи.
6. На главной откройте **Следующее действие** и отметьте прогресс.
7. Вернитесь в профиль, **измените бюджет/страну/интерес**, пересчитайте рекомендации и
   убедитесь, что результат и roadmap изменились.
8. Переключите язык (ru/kk/en): тексты AI меняются вместе с интерфейсом.

## Источники данных и AI/API

- **Каталог** (~23 вуза, ~31 программа) — демонстрационные данные, помеченные «Демо». Цены, сроки,
  пороги приблизительные. Реальные значения подтягиваются кнопкой «Проверить через интернет» с
  указанием источников. Дедлайны сопровождаются пометкой «демо» или источником.
- **Gemini API** (Google): диагностика, объяснения рекомендаций, чат, эссе-ревью, учебные гайды,
  веб-исследование. Ключ только на сервере, передаётся в заголовке, в логи не попадает.
- **Карты**: Leaflet, тайлы CARTO на данных OpenStreetMap (© OpenStreetMap contributors, © CARTO).
- **Ссылки на обучение**: поисковые ссылки YouTube, официальные сайты экзаменов.

## Ограничения

- Каталог вузов демонстрационный; реальные данные подтягиваются вручную кнопкой проверки.
- Бесплатный ключ Gemini имеет суточные квоты (особенно у поиска). При исчерпании включаются
  резервные модели и детерминированные тексты. Поиск в интернете может вернуть сообщение о лимите.
- Оценки шансов — статистические оценки с неопределённостью, а не гарантия поступления.
- Резервные пошаговые гайды обучения и заметки скорера частично на английском.
